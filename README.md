> 第九届传智杯全国大学生数智创新与AI应用大赛 - AI WEB网页开发赛道参赛作品
>
> 团队：智页 | 组别：本科B组

## 项目简介

AI智能学习助手是一款基于大语言模型与**RAG检索增强生成**技术的一站式个性化学习辅助平台。系统深度集成AI能力，覆盖"学—练—测—复习—诊断"完整学习闭环，通过检索用户个人学习数据（错题本、学习计划、知识点拆解、AI诊断报告）作为上下文，实现真正个性化的智能答疑与学习指导。

## 核心功能（七大功能）

### 1. AI智能答疑
- 基于火山方舟 DeepSeek 大模型的多轮对话答疑
- **RAG检索增强**：自动检索用户错题本、学习计划、知识点拆解、诊断报告，注入AI上下文，回答时引用个人学习数据，给出针对性建议
- 支持各学科问题解答、解题思路指导、学习方法咨询
- 对话历史保存，多会话管理

### 2. 知识点拆解
- 输入知识点名称，AI自动结构化拆解
- 包含定义、核心要点、举例说明、常见误区、延伸学习五个维度
- 历史记录管理，支持删除

### 3. 学习计划生成
- 根据科目、考试日期、每日学习时长自动生成个性化学习计划
- 按天规划，循序渐进，覆盖知识点梳理→强化练习→模拟冲刺阶段
- 支持多科目计划管理

### 4. 错题本管理
- 记录错题（科目、题目、你的答案、正确答案），AI自动分析错误原因并生成类似练习题
- 掌握程度三级跟踪（未掌握/部分掌握/已掌握）
- **艾宾浩斯遗忘曲线复习**：根据复习间隔自动安排复习提醒，科学抗遗忘
- 支持删除错题

### 5. 学习数据看板
- 学习数据统计概览（总学习天数、对话次数、知识点数、错题数）
- 最近7天学习趋势柱状图
- 错题科目分布饼图
- 各功能使用量统计

### 6. AI学习诊断
- 综合分析用户错题本、学习记录、知识点掌握情况
- 生成结构化诊断报告：薄弱科目识别、掌握度分析、针对性改进建议
- 历史诊断报告管理

### 7. 艾宾浩斯复习
- 基于遗忘曲线科学安排复习节奏
- 今日待复习错题自动提醒
- 复习后反馈掌握程度，动态调整下次复习时间

## 技术栈

### 后端
- Node.js + Express
- SQLite (better-sqlite3) — 单文件数据库，零配置部署
- JWT 身份认证 + bcryptjs 密码加密
- 忘记密码（安全问题验证）

### 前端
- 原生 HTML5 + CSS3 + JavaScript（零框架依赖，轻量高效）
- Marked.js（Markdown渲染）+ Highlight.js（代码高亮）
- Lucide 线性图标（本地化，离线可用）
- Inter 字体（本地化）
- 响应式设计，支持桌面/平板/手机

### AI能力（核心）
- **火山方舟 DeepSeek-V4-Flash** 大模型 API
- **RAG检索增强生成**：检索用户个人学习数据（错题本/知识点/学习计划/诊断报告），作为上下文注入大模型prompt，实现个性化智能问答
- 学科关键词匹配检索策略

## 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 8.0.0

### 安装步骤

1. **安装依赖**
```bash
npm install
```

2. **配置环境变量**
```bash
# Windows
copy .env.example .env
# 编辑 .env，填入你的火山方舟API密钥和推理接入点ID
```

3. **初始化数据库**
```bash
node db/init.js
```

4. **启动服务**
```bash
npm start
```

5. **访问应用**
打开浏览器访问：http://localhost:3000

## 获取火山方舟API密钥

1. 访问 [火山引擎控制台](https://console.volcengine.com/ark)
2. 注册并登录账号
3. 开通「开源LLM模型」服务（如DeepSeek系列）
4. 创建推理接入点（Endpoint），获取接入点ID（ep-开头）
5. 创建 API Key
6. 将 API Key 和接入点ID 填入 .env 文件

## 创新点

1. **RAG个性化智能答疑**：区别于普通AI问答，系统自动检索用户错题本、学习计划、知识点拆解、诊断报告等个人数据，注入大模型上下文，实现"懂你学情"的个性化回答。例如问"我数学有哪些薄弱点"，AI会基于你的实际错题进行分析。

2. **学练测复习诊断完整闭环**：AI答疑（学）→知识点拆解（学）→学习计划（练）→错题本（测）→艾宾浩斯复习（复习）→AI诊断（诊断），六大环节形成完整学习闭环，数据互通。

3. **艾宾浩斯遗忘曲线科学复习**：基于遗忘曲线算法自动安排复习间隔，复习后根据掌握程度动态调整下次复习时间，科学抗遗忘。

4. **AI诊断+数据驱动**：综合分析学习行为数据，生成结构化诊断报告，识别薄弱科目，给出可执行的改进建议。

5. **轻量化零依赖部署**：原生HTML/CSS/JS前端 + SQLite单文件数据库，无需安装数据库服务，npm install后一键启动，评委下载即可运行。

## 安全与隐私

- 用户密码使用 bcryptjs 加密存储
- JWT Token 身份认证
- API密钥通过环境变量配置，不硬编码在代码中
- 忘记密码采用安全问题验证方式，无需外部邮箱服务
